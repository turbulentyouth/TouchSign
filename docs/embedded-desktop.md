# 内嵌网页桌面版

**本机验证状态（2026-11-24）：**源码与 pythonw 独立窗口完整交互验收通过；最终 EXE 资源检查通过，但被 Windows 应用控制在创建进程时阻止，尚未通过冻结包运行验收。不能将其宣称为已经验证的可分发单文件程序。

本机双击入口为 `dist/TouchSign-Desktop.lnk`，它使用现有项目环境打开独立内嵌网页窗口，无浏览器标签页或命令行窗口。该快捷方式依赖项目目录及 .venv-runtime，不能单独拷贝到另一台电脑。可用 tools/create_desktop_shortcut.ps1 重建。

目标是保留触象的网页布局，在应用自己的 Windows 窗口中显示。没有浏览器标签页和地址栏，不启动 Edge 浏览器，不监听 127.0.0.1 端口。

HTML/CSS/JavaScript 随单文件 EXE 携带。前端通过 WebView2 消息接口与本地 Python 后端交换命令和状态；相机、ONNX 推理、机器人动作与语音均在本地运行。默认离线模拟，不自动连接或使能机械臂。

窗口使用 Win32/COM 直接调用微软签名的 WebView2Loader.dll；不需要 Python.NET、独立编译的窗口宿主或 Edge 浏览器启动命令。目标 Windows 电脑需有 WebView2 Runtime（当前电脑已确认安装）。开发环境用 requirements-desktop.txt，构建命令为 tools/build_desktop.ps1。

检测、停止和退出位于空载校准同栏，机械臂设置可展开/收起。检测只执行一轮：张开 → 到检测点 → 闭合压印 → 稳定识别/显示/播报 → 原位松开 → 确认释放 → 收回。保存检测点和收回点，不使用过渡点；配置位于当前用户 LocalLow/TouchSign/config.yaml。

## 验收入口

- `--diagnostics-report <绝对路径.json>`：模型、十二段语音、SDK/CAN DLL 与模拟动作检查。
- `--self-test-report <绝对路径.json>`：实际创建内嵌窗口，在真实 DOM 上点击设置、连接、示教、保存两点、检测，检查结果渲染和单轮结束，再关闭窗口，记录后台清理状态与截图。

自检不连接真实机械臂或传感器，示教数据写入临时测试配置。真机运动、夹爪释放、负载下重力补偿和传感器实际识别效果仍需现场验证。

旧版本“启动服务成功”仅证明后端监听，不能证明界面显示。桌面版以网页渲染和完整消息链路通过为交付条件，资源自检不替代界面验收。

真实页面验收包含：设置默认隐藏、检测与退出同栏、展开设置、连接模拟机械臂、开始示教、保存检测/收回两点、结束示教、收起设置、按钮触发一轮检测、结果显示为模拟鼠、等待后仍只有一轮、实际点击退出按钮、后台线程结束。图像预览在传感器断开时清空，不保留过期帧。
