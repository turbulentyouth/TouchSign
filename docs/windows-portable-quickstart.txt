TouchSign Windows 便携版（Windows 10/11，64 位 x64）

把整个 TouchSign-Windows 文件夹复制到 Windows，例如 D:\TouchSign-Windows。
如使用 ZIP，先完整解压，不能在压缩包里直接点 BAT。
无需安装 Python、CUDA 或配置环境。内含 CPU 训练和识别依赖、中文字体、最新模型和原训练数据。
建议放在较短、可写的路径；不要放在 Program Files 等受保护目录。

01_人工采集.bat
插好 USB 触觉传感器后双击。先看画面确认相机；Tab 换相机，Enter 确认。
按界面提示选择生肖，手工按压，空格保存；R 连拍，Esc 停止，Z/退格撤回，Q 退出。
保存的是已旋转 180° 的完整原图，不需要机械臂。原始数据在 data\manual。

02_一键训练.bat
先退出采集和识别窗口，再双击。程序自动读取新增采集和纠错数据，混合历史样本，最多训练 16 轮。
使用 CPU，不要求 NVIDIA 显卡；耗时取决于电脑和数据量。请等窗口显示完成。
没有新数据时直接提示，不重复训练。训练中断或失败时保留原模型。
旧训练/验证划分保持不变。新采集按整个会话划分；纠错按实际按压分组，避免连拍跨训练和验证。
新旧模型逐张比较：旧样本不能识别退步，正确置信度不能下降超过 15 个百分点；新增样本正确数须提高。
通过后，下次启动识别自动使用新模型；未通过则保留原模型。报告、日志和本轮权重都在 runs。
每轮新采集尽量重新打开采集窗口建立独立会话，补充不同按压位置；连拍不等于独立按压。

03_识别与纠错.bat
双击后自动打开本机浏览器。在相机列表选择触觉传感器，先空载校准，再手工按压识别。
识别错误时使用“保存纠错样本”，选择正确生肖，可填写按压位置，保存到 data\corrections。
退出时关闭启动的命令窗口（或在该窗口按 Ctrl+C）；仅关闭浏览器标签页不会停止相机服务。
不需要机械臂连接，不控制 NERO；所有数据处理和模型与当前人工测试方式一致。

04_回退上次模型.bat
先退出采集/训练/识别，再双击切换到上一个已启用的模型。再次双击可切换回来。
模型通过一个记录文件切换，随包原模型一直保留在 models\raw。

05_运行自检.bat
检查依赖、全部训练图片、模型一致性、ONNX/PyTorch 输出和程序互斥锁。
若遇到问题，请保留 logs\last-error.txt、logs\self-check.json 以及训练目录日志。

随包数据：334 张训练图（含 15 张纠错）、89 张固定验证图、13 张独立公鸡回归检查图。
不要删除 data\seed、data\regression、models、runtime 或已经启用模型对应的 runs 目录。
备份时复制整个文件夹，就能带走新数据、训练历史和当前模型。

验证边界：自检不代表 USB 相机在目标电脑已验证；请在采集入口确认画面。
模型仍采用预览模式。新增训练样本的正确率是拟合检查；目前缺少完整 unknown/空载独立验证。
